# 독립 Cartesian 텔레옵 동작 데이터

`g1_teleop_v3.npz`는 G1의 머리와 양손 위치를 각 축별로 독립적으로 바꾸는 합성 IK 데이터다. 기존 제자리/펀치/관절 사인파 데이터에서 부족했던 개별 손목 Z축 등의 추종 범위를 보완하기 위해 만들었다. 기존 파일은 수정하지 않는다. v1/v2는 개발 과정의 별도 산출물로 보존하며, 아래 재생성 명령은 마지막 복귀 구간의 길이까지 검증한 v3에 해당한다.

24개 클립, 클립당 16초·30 Hz이며 19개는 학습, 별도 seed로 만든 5개는 평가용이다. `SeedSequence(710000)`과 `SeedSequence(970000)`의 서로 다른 분기에서 난수를 생성한다. 양손 X/Y/Z 목표는 중립점 기준 각각 ±8 cm, 머리 X/Y는 ±3 cm, Z는 −5 cm부터 +0.5 cm다. 축마다 다른 1.5~3.5초 간격의 난수 knot와 5차 보간을 사용하며 마지막 중립 복귀 구간도 최소 1.5초다. knot와 양 끝에서 속도·가속도가 0이고 범위를 넘지 않는다. 고정 사인파를 사용하는 런타임 시나리오/추종 평가를 학습 데이터로 복사하지 않는다.

G1 배포 USD에서 추출한 정확한 FK를 사용해 29관절과 골반 높이를 CPU에서 최적화한다. 양발의 위치와 수평 발바닥, USD 제한 범위의 90% soft limit, 관절·골반 높이의 시간 평활화, 과도한 몸통 기울기에 대한 비용을 적용한다. 질량 기반 COM, 자기충돌 및 접촉 동역학은 최적화하지 않는다. **IK 오차가 작아도 학습 정책의 균형과 추종 성능이 검증된 것은 아니다.**

목표 계산은 런타임과 같은 골반 XY·중립 골반 높이 Z 기준 좌표계에서 한다. NPZ의 `keypoints`에는 최종 관절 자세의 **root-body FK 결과**를 저장한다. 데이터 로더는 Z에 `root_height − nominal_root_height`를 한 번만 더한다. 바라는 Cartesian 점 대신 실제 도달 가능한 FK 점이 정책 학습의 목표가 된다. 원래 목표와 실제 FK 점 사이의 오차, 발 위치·기울기, 관절 제한, 축별 목표/도달 범위, 난수 knot를 같은 이름의 JSON에 기록한다.

```bash
conda activate g1_teleop
python scripts/g1/prepare_teleop_motions.py \
  --output data/motions/g1_teleop_v3.npz \
  --clips 24 --seconds 16 --fps 30 --iterations 1000 --batch-size 4 \
  --merge-with data/motions/g1_mixed_v1.npz \
  --merged-output data/motions/g1_teleop_mixed_v3.npz
python -m unittest discover -s tests/g1 -p 'test_teleop_motion.py' -v
```

PyTorch/NumPy/SciPy가 필요하며 CUDA를 사용하지 않고 CPU 최대 4개 스레드로 계산한다. 출력 NPZ 또는 JSON이 이미 있으면 덮어쓰지 않고 종료한다. 재생성에는 새 경로를 지정한다. 선택적 통합 파일은 기존 데이터의 클립과 train/test 구분을 그대로 보존한다.

## 생성 후 확인한 v3 결과

`data/motions/g1_teleop_v3_validation.json`은 저장된 NPZ를 다시 읽어 NumPy FK와 원래 난수 목표를 대조한 결과다. 총 11,520프레임이며 모든 값이 유한하고 soft limit 위반은 0이다. 다음 값은 **요청한 Cartesian 점과 최적화된 참조 자세의 차이**이며, 정책 추종 오차가 아니다.

| 목표점 | 전체 평균 | 전체 95백분위 | 최대 | 평가 클립 평균 |
|---|---:|---:|---:|---:|
| 머리 | 2.98 mm | 14.81 mm | 28.41 mm | 2.90 mm |
| 왼손목 | 3.31 mm | 22.80 mm | 36.37 mm | 4.15 mm |
| 오른손목 | 2.34 mm | 17.98 mm | 51.06 mm | 1.36 mm |

범위 끝의 일부 동시 목표는 충분히 맞추지 못한다. 이 원래 목표를 모두 도달했다고 주장하지 않으며, 학습 파일에는 최적화된 자세로부터 다시 계산한 FK 목표만 넣었다. 따라서 이 표의 큰 잔차가 그대로 정책 학습의 불가능한 목표로 저장되지는 않는다. 저장된 FK 점과 재계산한 값의 최대 차이는 `1.50e-8 m`다.

- 실제 도달 참조의 왼손 X/Y/Z 전체 범위: 154.7 / 157.9 / 147.6 mm.
- 오른손 X/Y/Z 전체 범위: 156.9 / 156.8 / 143.3 mm.
- 고정 발 위치 오차: 평균 0.00394 mm, 최대 0.04589 mm.
- 참조 관절 속도: 전체 최대 2.959 rad/s, 99백분위 0.6615 rad/s. 클립 경계를 제외한 시간 차분이다.
- 골반 높이: 0.71318~0.77178 m. 실제 난수 knot 간격: 1.503~3.493초.
- 통합 파일: 29,339프레임, 85클립(학습 69 / 평가 16). 기존 클립의 관절·목표점·높이·명령·분할 배열은 원본과 정확히 같다.

v1에서 발견한 빠른 끝부분 복귀를 보완하기 위해 v2에서 중립 복귀·속도·가속도 제약을 강화했고, v3에서 마지막 knot 간격이 짧아질 수 있던 생성기 오류를 수정했다. 최대 참조 관절 속도는 v1의 6.524 → v2의 3.937 → v3의 2.959 rad/s로 감소했다. v1/v2 파일은 비교 기록으로 남겨 두었다. 새 단위 검사 3개에서 난수 경로의 범위·독립성·재현성, 마지막 구간을 포함한 시간 간격, 실제 IK 잔차·발 조건·관절 제한, NPZ 형식·분할·덮어쓰기 방지를 확인했다.

새 Cartesian 데이터는 이 프로젝트에서 생성한 독립 합성 데이터다. G1 기구학에는 [Unitree 모델](https://github.com/unitreerobotics/unitree_sim_isaaclab)의 출처가 적용된다. 기존 `g1_mixed_v1`과 합친 파일에는 H1 원본 리타게팅 데이터의 CC BY-NC 4.0 조건도 포함되므로 [MOTION.md](MOTION.md)의 출처·라이선스를 따른다. 모든 속도 명령은 0이며, 이 파일만으로 보행 학습이나 실제 Quest 연결을 검증했다고 볼 수 없다.
